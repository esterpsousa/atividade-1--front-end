# Atividade 01 – Frontend Web

### Professor: Genivaldo Carlos da Silva - 23/09/2026

## 📚 Sobre a Atividade

Esta atividade tem como objetivo aplicar os conhecimentos de **HTML5 e desenvolvimento Frontend Web** por meio da criação de páginas e sistemas web.

O trabalho apresenta seis propostas de projetos, cada uma com desafios técnicos, requisitos específicos e entregas que devem ser desenvolvidas em grupo.

## 🎯 Objetivos

* Aplicar a estrutura semântica do HTML5.
* Desenvolver páginas web com formulários e elementos de navegação.
* Utilizar corretamente campos, tabelas, imagens e links.
* Compreender conceitos de DNS, HTTPS e requisições HTTP.
* Aplicar boas práticas de acessibilidade e usabilidade.
* Organizar arquivos e pastas de um projeto web.

## 🚀 Projetos Propostos

### Grupo 1 – Landing Page para Lançamento de uma Startup

Desenvolver uma página institucional para uma startup fictícia, apresentando seu serviço digital.

**Requisitos:**

* Utilizar `header`, `nav`, `main`, `section`, `article` e `footer`.
* Apresentar título, descrição do produto e benefícios.
* Criar uma tabela de planos.
* Adicionar imagens e links.
* Definir um domínio fictício.
* Criar um diagrama do fluxo de acesso à página, envolvendo DNS, HTTPS, servidor e resposta HTTP.

**Entrega:** estrutura de pastas, `index.html`, diagrama do fluxo de acesso e justificativa do domínio escolhido.

### Grupo 2 – Página de Cadastro para uma Plataforma de Streaming

Criar uma página de cadastro para uma plataforma fictícia de streaming.

**Requisitos:**

* Utilizar `form`, `fieldset`, `legend`, `label`, `input`, `select`, `checkbox` e `button`.
* Criar campos para nome, e-mail, senha, data de nascimento e plano.
* Incluir o aceite dos termos.
* Aplicar validações como `required`, `minlength`, `maxlength`, `min` e `pattern`, quando necessário.
* Explicar a importância do HTTPS e por que o método POST, sozinho, não garante a segurança dos dados.

**Entrega:** página HTML funcional e apresentação das regras de validação utilizadas.

### Grupo 3 – Portal de Notícias de Tecnologia

Desenvolver um portal de notícias sobre inteligência artificial, desenvolvimento web, dispositivos móveis e segurança digital.

**Requisitos:**

* Utilizar `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`.
* Organizar cada notícia em um elemento `article`.
* Utilizar títulos com hierarquia correta.
* Adicionar parágrafos, imagens com `alt` adequado e links.
* Comparar uma estrutura feita com `div` com outra utilizando elementos semânticos.

**Entrega:** HTML corrigido e quadro comparativo entre estrutura genérica e estrutura semântica.

### Grupo 4 – Sistema de Inscrição para Evento de Tecnologia

Criar uma página de inscrição para a Semana de Tecnologia e Inovação de uma universidade.

**Requisitos:**

* Apresentar informações sobre o evento.
* Criar campos para nome, e-mail, telefone, curso e período.
* Permitir a escolha da modalidade de participação e das oficinas.
* Utilizar `radio`, `checkbox`, `select`, `option`, `fieldset` e `legend`.
* Aplicar validações nativas do HTML.
* Explicar por que o `placeholder` não substitui o `label`.

**Entrega:** arquivo `inscricao.html`, formulário testado no navegador e relatório dos erros detectados automaticamente.

### Grupo 5 – Loja Virtual de Produtos Sustentáveis

Desenvolver um catálogo on-line para uma empresa fictícia de produtos sustentáveis.

**Requisitos:**

* Criar uma página inicial com navegação e apresentação da empresa.
* Apresentar uma lista de categorias.
* Criar uma tabela comparativa de pelo menos três produtos.
* Incluir imagens, preços e links internos.
* Criar uma página `contato.html` com formulário.
* Utilizar caminhos relativos corretos para páginas e imagens.

**Entrega:** projeto com pelo menos duas páginas interligadas, pasta de imagens e mapa da estrutura de diretórios.

### Grupo 6 – Página de Agendamento para uma Clínica ou Serviço Profissional

Desenvolver uma página para agendamento on-line de serviços.

**Requisitos:**

* Apresentar o serviço oferecido.
* Criar campos para nome, e-mail, telefone, data, horário e serviço desejado.
* Adicionar um campo de observações.
* Utilizar `type="email"`, `type="tel"`, `type="date"`, `type="time"`, `select` e `textarea`.
* Aplicar o atributo `required`.
* Explicar a diferença entre `id` e `name` e quais dados seriam enviados pelo formulário.

**Entrega:** página HTML funcional e demonstração dos testes realizados com campos válidos e inválidos.

## 🛠️ Tecnologias e Recursos

A atividade trabalha principalmente com os seguintes recursos:

* **HTML5:** estruturação e organização do conteúdo das páginas.
* **Elementos semânticos:** organização do conteúdo de acordo com seu significado.
* **Formulários HTML:** coleta de informações e validação de campos.
* **Markdown:** documentação e organização das informações.
* **DNS, HTTPS e HTTP:** conceitos relacionados ao acesso e à comunicação com páginas web.

## 📁 Organização do Projeto

A estrutura de pastas deve ser organizada de acordo com os requisitos de cada grupo.

Exemplo de estrutura para um projeto HTML:

```text
projeto/
├── index.html
├── contato.html
└── imagens/
    └── imagem.png
```

Os arquivos e as pastas podem variar conforme o projeto desenvolvido.

## ✅ Considerações Finais

A atividade permite colocar em prática os fundamentos do desenvolvimento Frontend Web, trabalhando com estruturação de páginas, formulários, semântica, acessibilidade e organização de arquivos.

Cada grupo deverá desenvolver a solução correspondente à sua proposta, cumprir os requisitos apresentados e entregar os arquivos e as explicações solicitadas.
